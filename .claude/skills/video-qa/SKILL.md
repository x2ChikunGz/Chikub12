# Video QA (ต้องผ่านก่อนส่งคลิปทุกคลิป)

1. รันสคริปต์ (บังคับ): `python3 -I tools/video_qa.py clips/<ชื่อ>/<ชื่อ>.mp4`
   - FAIL = แก้แล้วรันใหม่ ห้ามส่ง · WARN = ส่งได้แต่ต้องบอกผู้ใช้
   - ได้ `qa_contact.jpg`, `qa_frames/f0-f5.jpg`, `qa_report.json`
2. ดูภาพด้วยตา (Read รูป): contact sheet ทั้งใบ + 3 เฟรมเต็มจาก qa_frames ตรวจ
   - เครดิต @เรื่องสงสัย ชิปซ้ายบน เห็นทุกช็อต (left:54 top:176)
   - ซับไทย+อังกฤษอยู่ y≈1500 ไม่ทับหน้า/ตัวหนังสือสำคัญ, ชิป/การ์ด y<=1380
   - ฉากมืดยังอ่านออกบนมือถือ (ไม่ดำสนิทเกินตั้งใจ), ไม่มีเฟรมที่ภาพพัง/ว่างโดยไม่ตั้งใจ
   - ตัวเลข/ชื่อในการ์ดตรงกับบท (ไม่ใส่จำนวนกลุ่มตัวอย่างที่แหล่งข้อมูลขัดกัน)
3. เสียง: ถอดกลับด้วย `python3 -I tools/transcribe.py` เทียบบท; บรรทัดที่คะแนนต่ำให้เจนใหม่ 3 seed
4. ไลเซนส์: ไม่ใช้ MusicGen/AudioGen ในคลิปจริง (CC-BY-NC); เสียงโคลน/พากย์ต้องเป็นโมเดลที่ใช้เชิงพาณิชย์ได้ (VoxCPM2 Apache-2.0); เสียง CC BY ต้องใส่เครดิตในแคปชั่น
5. รายงานผู้ใช้สั้นๆ: PASS/WARN ทุกข้อ + สิ่งที่ฟังด้วยหูไม่ได้ (บอกตรงๆ) + ความยาวถ้าเกิน 1 นาที
